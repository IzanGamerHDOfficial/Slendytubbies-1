# Slendytubbies 1 Source Code (2012)

> **Original Slendytubbies 1 source project for Unity 4.0.0f7 (2012).**

This repository contains the original source code of **Slendytubbies 1**, originally developed in **2012** using **Unity 4.0.0f7**.

The purpose of this repository is to preserve the game's original project and make it available for educational, archival, and research purposes.

> **Note:** This repository is **not** an official release from the original developer **ZeoWorks**.

## Unity 4 Licensing

As of today, **Unity 4.x can no longer be activated through Unity's official licensing servers**. Attempting to activate Unity 4.0.0f7 using a legitimate license will fail because the activation service has been discontinued.

To open and work with this project, **UniHacker is currently required** to bypass the obsolete licensing system.

# Opening the Project

1. Install Unity **4.0.0f7**.
